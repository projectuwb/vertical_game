# INKFALL — Technical Specification

Authoritative. Deviations must be logged in `DECISIONS.md` with a reason.

---

## 1. Platform targets

- **Primary:** installable PWA, portrait, touch, offline-capable, served from any static host. **The user deploys via Vercel connected to this GitHub repo**, so: keep the build output at `dist/`, ensure Vercel's zero-config Vite detection works (standard `package.json` with a `build` script), and commit a minimal `vercel.json` setting the correct headers — `Service-Worker-Allowed: /`, no caching on `index.html` and `sw.js`, immutable caching on hashed assets. Every push to the default branch must produce a working deploy; never leave the default branch in a state that fails `npm run build`.
- **Secondary:** Android app via Capacitor, producing a debug APK buildable locally with the free Android SDK. A release build requires the user's own keystore — generate the Gradle config for it and document the two commands, but do not attempt to sign.
- **Also works:** desktop browser with keyboard, as a development convenience.

Minimum: Chrome/WebView 100+, Safari 15.4+. No IE, no polyfills for anything older.

---

## 2. Stack

- **TypeScript 5.x, `strict: true`,** plus `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
- **Vite 5** for dev server and build.
- **Canvas 2D** for rendering. Not WebGL, not three.js. Justification: the art direction is flat ink shapes with a custom projection, Canvas 2D handles it at target framerate with layer caching, and it removes an entire class of shader/context-loss bugs from an unattended build. If profiling on the perf budget (§8) proves Canvas 2D insufficient at 900 enemies, the fallback is a hand-written WebGL sprite batcher for Blot and Strokes only — log that decision if you take it.
- **Vitest** for unit tests.
- **ESLint + Prettier**, flat config, no framework plugins.
- **Capacitor** (dev dependency only) for the Android wrapper.

**`dependencies` must be empty.** Everything at runtime is first-party code. No physics engine, no ECS library, no tween library, no audio library, no state library, no UI framework. Write what you need.

## 4. Loop, timing, determinism

- **Fixed timestep** simulation at 60Hz with an accumulator, max 5 catch-up steps per frame, render interpolated by the leftover alpha.
- Simulation consumes an immutable `InputFrame { lateralDelta, holding, dtFixed }` produced by `/platform/input.ts`. The sim never touches the DOM.
- **PRNG:** mulberry32, seeded per Passage. One generator per concern (`director`, `gates`, `slips`, `seals`, `cosmetic`) so adding a cosmetic roll never shifts gameplay rolls. `Math.random` is banned outside `/render` cosmetics — add an ESLint rule enforcing it.
- Every Passage records its seed and the upgrade state; the summary screen exposes the seed in Settings for reproducing a run in the harness.

---

## 5. Projection and rendering

**Projection.** World space is `(x, y, z)` with `z` forward, `y` up, camera at `(0, 4.2, −6.5)` looking at `(0, 0.8, 14)`. Use a simple perspective divide:

```
const d = z - camZ;                    // depth ahead of camera
const s = focal / max(d, nearClip);    // scale factor, focal ≈ 9.2, nearClip 0.6
screenX = cx + (x - camX) * s * unit;
screenY = cy - (y - camY) * s * unit + horizonOffset;
```

Draw strictly back-to-front (painter's algorithm) using a depth-bucketed draw list — 64 buckets over the visible z-range, refilled each frame from pooled arrays, never sorted with `Array.sort` in the hot path.

**Layers.** Four offscreen canvases composited each frame:
1. **Sky/water** — regenerated only on resize or palette change.
2. **Road + trail** — the trail accumulates here with a per-frame 6% alpha fade, which is both cheap and exactly the right look.
3. **Actors** — cleared and redrawn every frame.
4. **HUD** — redrawn only when its values change (dirty-flagged).

**Perf discipline.** Pre-allocate pools for projectiles (2048), blot (1200), strokes (999), particles (600), floating numbers (64). Zero allocation in `update()` or `draw()` — verify with a test that runs 600 sim steps and asserts heap growth stays under a threshold. No string concatenation per frame; cache formatted numbers.

**Density blocks.** Above 60 Strokes, draw the back rows as filled polygons with a class-stippled fill rather than individual figures (see `GAME_DESIGN.md` §5). Same for Blot above 150 units: individuals within 30u, silhouetted mass beyond.

## 6. The balance harness (build this early — Task 2.7)

A headless runner that imports only `/sim` and `/meta`, runs Passages with a scripted bot, and reports.

```
npm run sim -- --runs 2000 --strategy mixed --upgrades 0 --seed 12345
npm run sim -- --sweep slipBudget=12,18,24,30 --runs 500
```

**Bot strategies** (all must be implemented; they're the measuring instrument):
- `greedy-slips` — always aims at the nearest Slip, ignores the Blot until it's within 6u.
- `greedy-kill` — always aims at the densest Blot cluster.
- `mixed` — targets Slips unless projected Blot arrivals in the next 2s exceed current `N × 0.4`.
- `gates` — as `mixed`, but additionally evaluates gate pairs by expected value.
- `random` — noise floor.

Output `BALANCE_REPORT.md`: histograms (ASCII) of Passage length, peak Line, death cause, Gold Leaf per run, plus a pass/fail table against `GAME_DESIGN.md` §11. **Regenerate it after every tuning change and commit it.** Balance is not a vibe here, it's a build artefact.

## 7. Fonts and assets

Vendor two OFL fonts as subset `.woff2` (Latin, digits, punctuation only — target under 40KB each): **Shippori Mincho B1** and **Zen Kaku Gothic New**. If subsetting tooling is unavailable offline, vendor the full Latin subsets from the font's own OFL-licensed release and note it. Include `OFL.txt` for each in `/src/assets/fonts`. `font-display: block` for the display face (gate numbers must never render in a fallback), `swap` for UI.

**No image files.** App icons (192, 512, maskable) and the splash are generated at build time by a Node script that draws them with the same Canvas code as the game, so the icon is literally a brushstroke rendered by the engine. Wire it into `npm run build`.

---

## 8. Performance budget

- 60fps sustained with 400 Strokes and 900 Blot units on a Snapdragon-695-class device. Fall back gracefully: an adaptive quality manager drops particle count, then trail resolution, then density-block thresholds, if the rolling 30-frame average drops below 52fps for 2s. Never drop simulation rate.
- Initial payload ≤ 400KB gzipped excluding fonts; total ≤ 600KB.
- Cold start to playable title ≤ 1.5s on mid-range Android.
- Memory ceiling 180MB.

Add `npm run perf` — a scripted stress scene at maximum entity counts that logs frame-time percentiles. Commit the numbers to `PERF.md`.

## 9. Persistence

`localStorage` key `inkfall.profile.v1`, JSON, with `schemaVersion` and a migration chain (`migrations.ts`) so future versions never wipe progress. Contents: Gold Leaf, upgrade levels, best distance, best Line, Seals broken, total Passages, settings, unlocked Brushes/Scroll progress (phase 6), and a 40-run rolling history for the harness to compare against.

Wrap all access in `/platform/storage.ts` with try/catch — private-mode Safari throws, and the game must run fine with persistence silently disabled (in-memory profile, one quiet line on the settings screen).

Include export/import of the profile as a copyable JSON blob in Settings. It's 20 lines and it saves the user from a cleared cache.

## 10. PWA

- `manifest.webmanifest`: name "Inkfall", `display: standalone`, `orientation: portrait`, theme `#2A3440`, background `#171E26`, generated icons, `id`, `scope`, `start_url`.
- Hand-written service worker (no Workbox): precache the built asset manifest at install, cache-first for hashed assets, network-first with cache fallback for `index.html`, and a version bump that clears old caches on activate. Runtime must work with the network fully off — verify in a test that fails if any runtime `fetch` to an external origin exists in the bundle.
- An unobtrusive install prompt: a single line on the title screen after the `beforeinstallprompt` event, dismissible permanently.
- Safe-area insets honoured (`env(safe-area-inset-*)`), `viewport-fit=cover`, `user-scalable=no`, overscroll and pull-to-refresh disabled, wake lock requested during a Passage where supported.

---

## 11. Android

- Capacitor wraps the built `dist/`. `appId: com.inkfall.game`, `appName: Inkfall`.
- Lock portrait in the manifest, fullscreen/immersive, hardware back button mapped to pause/back-out (never straight to exit from a Passage), no permissions requested at all — verify the merged manifest declares zero.
- Haptics via Capacitor Haptics on Seal impact, Flourish, and Line loss; degrade silently on web.
- Document in `README.md`: `npm run build && npx cap sync android && cd android && ./gradlew assembleDebug`, and where the APK lands. Also document the release path (`assembleRelease` + a keystore the user generates with `keytool`) without executing it.
- If the Android SDK isn't present in the environment, still generate and commit the full `/android` project and the docs, and note in `PROGRESS.md` that the APK build is unverified. Do not block on it.

## 12. Testing

- **Unit** (vitest): gate maths, phrase detection, formation layout, wetness economy, damage pipeline including armour multipliers, economy/cost curves, save migrations, PRNG determinism.
- **Determinism test:** same seed + recorded input tape produces byte-identical world hashes at steps 100/1000/5000.
- **Regression test:** a committed set of 20 seeds with expected outcome ranges; fails loudly if a change shifts balance unintentionally.
- **Allocation test:** as §5.
- **No-network test:** as §10.
- Target ≥80% line coverage in `/sim` and `/meta`. Do not chase coverage in `/render`.

`npm run verify` = `typecheck && lint && test && build`. This is the gate for every task.

---

## 13. Code standards

- No `any`. No non-null assertions outside pool internals. Discriminated unions for entity variants.
- All tunable numbers live in `/sim/config.ts` as a single frozen, typed, commented `BALANCE` object mirroring `GAME_DESIGN.md`. Nothing anywhere else is a magic number. The harness sweeps by overriding this object.
- All user-facing strings in `/ui/strings.ts`.
- Comments explain *why*, not *what*, and are mandatory on anything non-obvious in projection, director, and phrase logic.
- Conventional commits, one per task.
- `README.md` kept current: what it is, how to run, how to build, how to sim, how to package.
